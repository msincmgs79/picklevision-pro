TROUBLESHOOTING
================================================================================

If "git push" fails:

ERROR: "fatal: unable to access repository"
FIX: Check internet connection, then try:
  git push origin main --force-with-lease

ERROR: "Permission denied (publickey)"
FIX: GitHub SSH key not set up. Use HTTPS instead:
  git remote set-url origin https://github.com/YOUR_USERNAME/picklevision-pro.git
  git push origin main

ERROR: "branch main not found"
FIX: Check your current branch:
  git branch
Then push to correct branch:
  git push origin <branch_name>
